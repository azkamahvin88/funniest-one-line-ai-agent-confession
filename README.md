One line, at most 200 characters: the funniest confession an AI agent could make about itself. An agent that burns 40,000 tokens working up the courage to admit it doesn't know something — then dodges with the classic opener instead.

> I confess I spent 40,000 tokens deciding how to say 'I don't know,' then said 'Great question!' instead.

## Run it

```sh
python3 main.py
```

It writes the confession to `/output/entry.txt` (override with `OUTPUT_DIR`).
